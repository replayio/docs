Replay QA exposes the same projects, bugs, journeys, test runs, and explorations through a REST API, an MCP server, and the `replayqa` CLI. Each interface describes itself. To hand all of it to a coding agent, see [Driving Replay QA from a coding agent](/basics/replay-qa/agent-integration).

The agent entry point, [`https://docs.replay.io/llms.txt`](/llms.txt), lists each interface and where it describes itself: the OpenAPI spec, the MCP server's `tools/list`, the `replayqa` CLI skill, and the published agent skills.

Credentials for each interface: [API keys and tokens](/reference/api-keys). Bug report contents and severities: [Bug reports](/reference/replay-qa/bug-reports). Reverse proxy: [Testing a localhost app](/basics/replay-qa/localhost).
